# 🎮 Kahoot 题目使用说明

文件: `kahoot_questions.tsv` — **35 道题目** (覆盖 D1-D4 全部内容)
适用于 D5 上午 Session 1 的「分组比赛」(约 30 分钟, 1 题约 30-50 秒)

## 题目分布

| 单元 | 题目数 |
|---|---|
| D1 艺术是表达 (心情/形式) | 5 |
| D2 三位大师 (毕加索/马蒂斯/梵高) | 10 |
| D3 中国水墨画 (工具/特点/画家) | 10 |
| D4 当代艺术 (达利/马格利特/草间弥生/杜尚) | 8 |
| 综合 / Wrap-up | 2 |

每题 4 个选项, 时间 20-30 秒。

## 导入到 Kahoot

### 方法 1: 用 Kahoot 官方模板 (推荐)
1. 登录 [kahoot.com](https://kahoot.com), 点击 "Create" → "New Kahoot"
2. 点击 "Import questions" / "Import spreadsheet"
3. 下载 Kahoot 的 .xlsx 模板
4. 把 `kahoot_questions.tsv` 用 Excel 打开 → 复制到 Kahoot 模板的对应列
5. 上传模板到 Kahoot

### 方法 2: Excel/Numbers 转换
1. 在 Excel / Google Sheets / Numbers 里打开 `kahoot_questions.tsv` (它是 Tab 分隔的)
2. 另存为 `.xlsx`
3. 上传到 Kahoot

### 方法 3: 直接复制粘贴
- 在 Kahoot Quiz 编辑器里, 一道一道复制题目和选项

## 使用建议

- **分组**: 4-5 人一组, 每组一台手机 / 平板
- **节奏**: 每题答完后留 30 秒讨论 + 解释
- **奖励**: 累计积分, 最终前 3 名给小奖品
- **难度调整**: K-2 学生可以减少题数, 老师朗读题目和选项
- **趣味变体**: 不用电子设备的话, 也可以打印题卡, 全班举手抢答 / 小组板书答案

## 兼容其他平台

这个 TSV 格式也可以用于:
- **Quizizz** — 有类似的 Excel 导入功能
- **Blooket** — 创建 quiz 时可批量导入
- **Google Forms** — 手动复制粘贴
- **Mentimeter** — Quiz Competition 模式

## 自定义建议

老师可以根据班级实际情况:
- 增加 / 减少题目
- 修改选项顺序 (Kahoot 答案位置 1-4)
- 加入图片 (Kahoot 支持每题配图 — 用《图片参考》文档里的画作)
